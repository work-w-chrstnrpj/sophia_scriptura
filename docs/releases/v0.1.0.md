## Included

- **Repository presentation:** redesigned README with parchment/sage light-and-dark
  SVG artwork, a native workflow-status badge, latest-release navigation, feature overview
  and expandable setup/verification documentation. This documentation follow-up changes
  no application behavior; native tests were not rerun for it.

- **Scripture:** offline bundled WEB reader, edition-aware navigation and selections,
  Pencil annotation layers, bookmarks, gleanings, links and sharing. Licensed editions
  remain subject to provider access and content permissions.
- **Study hubs:** Verse Hub collects verse-anchored study items; Chapter Hub groups links,
  chapter conversations and verse conversations. The Chapter control appears alongside
  Annotations and Actions. Chapter chats send a reference rather than an entire chapter.
- **Companion:** bring-your-own-key conversations, prompt presets, Markdown responses,
  content-sized user bubbles, contextual Ask from both Scripture entry points, and
  selection-aware Original Language Analysis. Ask starts with a blank question composer;
  authorized verse text and translation accompany the submitted question.
- **Sources and models:** publisher passage links, supplied reference links and labeled
  searches when a direct link is missing. Generated references are not proof of retrieval.
  New manual Scripture Ask chats correct the Groq ALLaM fallback; existing conversations
  keep their selected model. Known drafting artifacts fail with a retry/model notice.
- **Quiz Me:** structured quizzes, saved results and local question-cache coordination.
- **Notes:** Canvas, Page, Prayer and Journal note types; typed and Pencil study workflows,
  shared color choices, prayer updates and library filtering/organization.
- **Collections:** persistent folders, nested organization, personalized icons/colors,
  artifact summaries and shared destinations. No Folder is a fixed neutral virtual tray.
- **Activity:** study sessions, reading tracking, local metrics, reminders, meditation
  journeys and background-music controls. Scripture narration is not part of this release.
- **Settings:** archive browsing/restoration and category-specific data deletion with
  typed confirmation. Deletion is permanent; export available backups before using it.
- **Republished additions:** local profile editing (name, optional birthday, church and
  photo), personalized empty Scripture-conversation greetings, revised note destination
  and metadata controls, and related Notes/Companion presentation refinements.
- **Latest additions:** separate Trash and Archive behavior, 30-day trash retention,
  restore/permanent-delete controls, compatibility guidance, Settings About/version
  information and bundled legal notices. The owner-supplied root license now declares
  GPL-3.0-or-later; bundled third-party content retains its own terms.
- **Release tooling:** a GitHub Actions workflow can build/test and publish a missing
  version tag on `main`. Consolidation triggers that workflow; manual publication does
  not imply hosted-runner verification passed. The known unit-test blocker remains.

## Installation and data

Open `application/SophiaScriptura/SophiaScriptura.xcodeproj`, select the SophiaScriptura
scheme, configure the owner's Personal Team and run on the paired iPad. Follow the
[installation guide](../deployment/deployment.md). Free-account signing normally requires
weekly redeployment. This release does not include an IPA, server or App Store deployment.

Install in place to retain the existing app container; do not uninstall as an upgrade step.
Keep exports before updating. Feature-specific backups are not a guarantee of full-app
recovery. Provider credentials stay in device Keychain and are not included in the release.

## Known limitations

- AI output can be inaccurate, fabricate references or ignore instructions. Request,
  formatting and source-link tests do not establish live-provider factual accuracy.
  Independently verify lexical claims, quotations and cross-references.
- Existing poor responses are not rewritten. Start a new Ask or select a suitable model
  before retrying an old conversation.
- No live-provider calls or destructive owner-data checks are part of release publication.
- Physical Pencil, accessibility, layout and recovery checks are distinct from simulator
  tests. The owner previously accepted the M9 personal-use workflow; later changes still
  need their own device acceptance.
- M7 Scripture narration was abandoned and is excluded. Provider/translation rights
  and licensed-content restrictions continue to apply.
