# Sophia Scriptura v0.2.0

Release date: **2026-10-05**. Personal-use source notes for the Notes writing release.
App marketing version: **0.2.0**; build number: **16**.

The Release workflow verifies the `main` snapshot before creating tag `v0.2.0` and
publishing these notes. Earlier device installations are recorded separately below.

## Included

- **Notes ink:** PencilKit keeps document-coordinate drawings and freezes viewport sync
  while the Pencil is down to avoid mid-stroke scroll distortion.
- **Page and Journal scale:** zoom stays at 100%. Pinch zoom and the zoom menu stay on
  Canvas. Vertical scrolling remains.
- **Page and Journal pan:** left and right movement is available only while the Scripture
  pane is open. With the pane closed, the page stays horizontally fixed.
- **Page and Journal toolbar:** one row with the Apple Pencil control, text formatter,
  checkbox, table, and link. The link menu inserts a link, takes a photo, chooses a photo,
  scans text, scans a document, records audio, or attaches an audio file.
- **Text styles:** bold, italic, underline, strikethrough, heading levels, ink colors and
  block quotes are optional spans on the page body, alongside list and indentation controls.
  Empty formatting is omitted. New Canvas object fields default when opening older notes.
- **Canvas controls:** object palettes include position locking and layer ordering.
- **Notes library:** type filters apply to the library and archive; load failures expose
  retry and a separately confirmed local Notes reset.
- **Scripture annotations:** palette controls and picker handoff from Notes are refined.
- **Appearance names:** Settings shows **Old Paper** and **Firmament’s Library**. Stored
  identifiers remain `oldPaper` and `midnightLibrary`.

Prayer previews fit the writing column to the card. The new insert row is Page and Journal.

## Installation and data

Earlier v0.2.0 development builds were installed in place on `iPad ni Paj` as
`com.personal.SophiaScriptura`. Those installations do not verify this final source snapshot. Follow
[deployment](../deployment/deployment.md). Free-account signing still needs weekly
redeployment. This release does not include an IPA.

Camera and microphone prompts appear the first time a photo, scan, or recording is used.
Existing objects remain readable without the new editor fields; no reset is needed to
upgrade. New audio attachments are not supported by v0.1.0, so do not assume archives
containing them can be reopened by that older version.

## Known limitations

- Live-stroke feel on the physical iPad remains the acceptance check for the ink changes.
- Scan Text uses on-device recognition and can miss handwriting or faint print.
- Audio attachments are capped at 16 MiB. Recording uses the shared audio session and can
  interact with background music.
- No live-provider calls or destructive data checks are part of this install.
