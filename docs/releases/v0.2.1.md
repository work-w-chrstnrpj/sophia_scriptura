# Sophia Scriptura v0.2.1

Release date: **2026-10-05**. App version **0.2.1**, build **18**.

Notes bulk Delete now presents its confirmation directly on the Delete button and
captures the selected note IDs when tapped. Cancel keeps the selection; Move to Trash
moves only those notes into recoverable Trash. No storage schema change or reset is required.

The focused UI regression passed on simulator and physical iPad, covering cancellation,
portrait/landscape confirmation, unselected-note retention and relaunch persistence.
Results: `build/notes-bulk-delete/after.xcresult` and `ipad-after.xcresult`.
The original missing-dialog report was not reproduced in isolated tests; owner acceptance
of that specific interaction remains pending.

GitHub Release publication requires the hosted simulator build and full unit suite to pass.
This is a personal source release without an IPA. Follow the
[deployment guide](../deployment/deployment.md) for in-place installation and weekly
Personal Team signing. Existing app data is retained; Trash has 30-day recovery.
