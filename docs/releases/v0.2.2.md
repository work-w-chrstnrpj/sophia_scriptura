# Sophia Scriptura v0.2.2

Release date: **2026-10-07**. App version **0.2.2**, build **19**.

Collections now exclude archived, trashed and missing notes/conversations from material
lists, picker choices and counts while preserving recoverable memberships. Add Study
Material offers New Note and New Conversation, assigns the new material to the current
folder and opens its editor. Conversation creation retains existing provider requirements.

Canvas now shares an image through the system share sheet, displays correctly colored
palette swatches, and routes the Pencil selection tool to object taps and a freehand
selection loop. A second tap on selected text enters UIKit text editing. Editor Delete
buttons are red. Selection works on whole objects, including ink batches; individual
stroke selection and full Freeform parity are not included.

Canvas strokes reuse ink objects in batches of up to 64 rather than consuming one object
per stroke. Notes capacity increases from 200 to 1,000 combined objects/attachments;
existing byte and drawing safety limits remain. Rejected drawing edits restore saved ink
instead of retrying on each refresh. Unchanged ink scenes/drawings and bounded rasters are
reused; off-screen Canvas object views are culled while selected/edited objects stay mounted.
ImageIO import, downsampling and displayed-image decoding run on a serial background worker.
Whole-Canvas sharing prepares off-screen objects and awaits image decoding before export.

## Verification and remaining acceptance

- 216 unit tests passed in `build/v022/cache-final.xcresult`, including capacity,
  archive/trash visibility, 300-stroke batching/save/reopen, cached-scene equivalence,
  viewport culling/selection pinning and image preparation.
- Focused simulator UI checks passed for Collection create/assign/open and Canvas color/share.
  Saved screenshots confirm colored swatches and red editor Delete.
- A 30-second physical iPad trace of installed v0.2.1 established a CPU baseline.
  It does not prove a performance improvement in this release.
- Sustained Pencil drawing, erase/undo, selection, zoom/reopen and responsiveness on the
  new build still require physical acceptance. No full-app or physical performance pass
  is claimed. See [SP-024](../../tickets/SP-024-v022-study-material-and-canvas-fixes.md).

No schema migration or app-data reset is required. Older builds may reject notes above
200 objects; keep a Notes backup before downgrading. Page/Journal/Prayer retain 16 MiB ink
payloads and the 10,000-stroke safety bound. Scripture retains its separate 32 MiB drawing
limit and 64 MiB aggregate bound.

The GitHub Release workflow requires its hosted simulator build and full unit suite to pass
before publication. This is a personal source release without an IPA; use the
[deployment guide](../deployment/deployment.md) for in-place Personal Team installation.
