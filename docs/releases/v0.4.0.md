# Sophia Scriptura v0.4.0

Release date: **2026-10-10**. App version **0.4.0**, build **21**.

## Sophy and Lady Wisdom

Sophy adds an on-screen companion enabled through Settings, an adaptive chat interface,
dedicated History, slash commands and previewed study actions. Settings also offers Sol
(Ecclesiastes) and Sabinus (Job), with optional idle Scripture quotes and a configurable
idle delay; all share the same study session and provider route. She can help organize
collections, create reminders and Activity records, start music, route to Quiz Me or
Contemplation, and summarize eligible study content and activity insights. Missing action
details require clarification; locked study content remains excluded. Notes text selection
supports grammar, tone, organization, expansion and rating operations with explicit review
before replacement. Sophy history and action journals use local generation persistence;
study backup includes Sophy data. See [SP-029](../../tickets/SP-029-v040-sophy-lady-wisdom.md)
and [review evidence](../testing/sp029-sophy-review.md).

Hugging Face is available as an OpenAI-compatible BYOK provider, with shared model routing
and Keychain credentials. Actual provider/model access depends on the owner's account.

## Music and Activity outside Sophia

Native Now Playing/remote music commands and a privacy-safe Activity Live Activity project
committed study state onto supported system surfaces. Widget extension packaging and
background-audio declarations are included. System placement varies by iPadOS/device;
this does not add a permanent Home-screen notch. See [SP-030](../../tickets/SP-030-background-music-and-activity-system-controls.md).

An explicitly opened AVKit PiP player displays music and/or generic Activity elapsed time.
Both active services appear together; Play/Pause controls music when present, otherwise
Activity. Seeking does not change either service. Return to App opens existing controls.
Closing PiP does not finish Activity or stop music. Settings → Floating Player → Allow
Picture in Picture persists the owner's choice (default on); off hides its launcher,
closes PiP and prevents entry while the underlying services continue. See
[SP-031](../../tickets/SP-031-study-picture-in-picture.md).
