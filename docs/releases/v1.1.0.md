# Sophia Scriptura v1.1.0

Release date: **2026-10-13**. App version **1.1.0**, build **23**.

## Notes and Collections

- Drag root and nested folders onto other folders to reparent their subtree, or use Move Collection for the complete destination tree and top-level destination. Cycles, virtual No Folder and inaccessible destinations are rejected.
- Page notes gain Page Status: Unset, Drafting, Revising, Editing, Publishing and Closed. Long-press notes to change Page/Prayer status or Journal Emotional/Mental State without opening an editor, including Collection note rows.
- Notes and Collection note cards share appearance, previews, dates and animated rubber stamps. Closed Pages show green PUBLISHED; answered prayers green ANSWERED; redirected prayers yellow REDIRECTED. Oversized stamps overlap card text with stable per-note 1–15 degree tilt. Entry animation darkens a shadow before revealing the status color; Reduce Motion shows the final mark directly.
- Journal cards show Emotional and Mental State on one row, with consistent flower/heart symbols for Thriving/unset emotion. Page cards restore opening-text previews until Closed.
- Each Collection folder offers remembered List/Card layouts with uniform geometry across material types. Notes opened from Collections use a full-screen shared editor and return to the same folder.

## Activity and Companion

Activity charts gain animated reveals with Reduce Motion support, and record-detail actions receive larger controls. Quiz Me can append another round to one session, accumulating questions, score and recorded activity time; history displays the round count. Quiz activity imports update the existing linked record rather than duplicating it.

## Compatibility and acceptance limits

Page Status and quiz round count are additive metadata with defaults for older records. Older app versions may drop newer metadata when rewriting records; preserve backups before downgrade. No storage reset or migration is required by this release. Folder moves retain item identities and their own protection settings; inherited access follows destination ancestry.

This is an owner-requested personal source release, not App Store distribution. Rubber Stamp wordmarks are rendered from the personal-use font; see [font provenance](../design/stamp-font-provenance.md). No source font file, personal study data, provider credentials or provisioned IPA is attached.

Physical animation timing, Pencil, accessibility, protected-folder and actual-owner-data upgrade acceptance remain open. Real-provider repeated-round quiz behavior and full-app/manual matrices are not established by simulator tests. Earlier signed installations and launches establish deployment only. v1.0.0's provider/content acceptance gaps remain applicable. Publication does not claim these gates complete.

## Verification

The versioned release snapshot passed **376 unit tests, zero failures** on iPad (A16) Simulator (`build/v110/unit-tests-final.xcresult`). The first run found a completed-quiz activity-recording regression and a malformed multi-round mock fixture; restoring the documented recording behavior and supplying two complete cached rounds resolved both. The repeated-round check now asserts accumulated score and continuous question indexes. Whitespace, plist and staged credential-pattern checks passed. The full UI suite and manual acceptance matrices were not rerun in this release session. Prior focused evidence includes the shared-card Collection/Journal/Page/Prayer UI checks (`build/sp040/shared-note-cards.xcresult`), status persistence and hold menus, folder drag/reopen tests, plus successful in-place iPad installation/launch. These earlier focused runs do not replace final snapshot verification. The hosted Release workflow independently builds and runs the unit suite before publishing the tag and GitHub Release.
