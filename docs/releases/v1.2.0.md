# Sophia Scriptura v1.2.0

Release date: **2026-10-14**. App version **1.2.0**, build **24**.

## Collections

Adds automatic Smart Order for Bible-book and numbered subfolders, with per-folder arrangement overrides. Loaded edition order is preferred for recognized book names. No Folder color is editable and persists. Material lists use lazy rows and explicit item action menus; notes can be archived/trashed, conversations moved to Companion Trash, and passages/links deleted through their existing commands. Notes whose only folder is trashed appear in No Folder and can open there; restoring the folder restores its filing context. Shared note card presentation and Collection-local note navigation are retained.

## Sophy and providers

Sophy gains descriptive slash-command suggestions/help with backward-compatible short aliases, plus deterministic recognition of requests for a Bible/Testament/book folder tree before generic folder parsing. Qwen China and International adapters are added with region-specific endpoints and errors. Curated model fallback is enabled. Qwen models are not labeled free: trial quota is account-specific and may expire or fall through to paid use; check the provider console before sending requests.

## Planning documents

Includes draft SP-041 MCP bridge, SP-042 selected handwriting transcription, and SP-043 lasso-based Sophy enhancement tickets. These are planning only; those features are not implemented by this release.

## Compatibility and acceptance

No storage reset is required. Existing Collection snapshot unfiledAccent now drives the editable virtual-folder color. Per-folder layout/order choices remain local UI preferences. Existing access guards, legacy metadata and provider keys are retained; credentials and study data are not attached to this source release.

This is an owner-authorized personal source release, not App Store distribution. Physical Pencil, accessibility, chart/stamp animation, actual-owner-data upgrade, protected-folder and live Qwen/account/region acceptance remain open. Simulator/mock checks do not establish provider cost, quota, available models or real network behavior. Earlier v1.0.0/v1.1.0 content/provider acceptance gaps remain applicable. No physical installation is included in this publication task.
