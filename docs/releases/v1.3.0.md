# Sophia Scriptura v1.3.0

Release date: **2026-10-15**. App version **1.3.0**, build **25**.

## Points to Ponder

Create a reflection question from Collections → a folder or No Folder → Add Study
Material → New Point to Ponder. Open the question to Close, Delete or Explore it.
Explore presents a separate modal to send the question to Companion or create a note
with the question as its editable title. Companion uses the configured provider/model,
existing preset and normal send/retry pipeline. The source question stays saved.
Deleted questions can be restored in Settings → Trash → Points to Ponder during the
30-day retention period.

## Saved passage conversions

Bookmark cards offer **Turn into a Gleaning**, retaining passage identity, translation,
exact excerpt and folder assignments. Gleanings offer **Turn into a Note** with title
`Gleaning from "Book Chapter:Verse (Translation)"` and reference, passage text and
insight content. Sources remain saved; cancelling creates nothing. New notes inherit
accessible folder assignments. Both conversion buttons sit below **See the whole
chapter**, using matching full-width dimensions and transparent outlined styling.
Save/folder choices now exclude trashed and archived collections.

## Collections, Notes and Journal

Collections/Notes records and Prayer updates gain swipe actions with one open rail,
swipe-back closure and dismissal on vertical scrolling. Existing long-press actions
remain available. Collection item cards/lists omit the permanent ellipsis.

Duplicate Collection copies the active folder/subfolder tree; Include contents reuses
existing study items in the new folders. Duplicate Note creates an independent local
copy. Protection and access guards remain. Deleted annotation layers disappear from
saved material when confirmed by the loaded annotation snapshot; removing a stale
reference leaves the underlying ink untouched.

Page/Journal editing tools can retract. Journal Type supports Unset (book), Diaristic
(quill) and Spiritual (owl), including native-menu icons. New journals start Unset;
legacy/unknown type values retain the Spiritual default. Subfolder previews include
direct child-folder counts and a plain Arrange label.

## Compatibility and verification

Collections schemas 1/2 load without points; stores containing points write schema 3,
which older builds reject safely. Notes gains additive Journal Type metadata; existing
bodies, ink, provider keys and app data are retained. No reset is required.
