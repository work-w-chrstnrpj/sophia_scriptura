# Sophia Scriptura v1.3.1

Release date: **2026-10-16**. App version **1.3.1**, build **26**.

## Collections fixes

- Saved links now offer **Edit** in their open modal, including the Scripture hub,
  and **Edit Link** in Collections hold/swipe actions. Change the title or URL;
  invalid/non-http(s) addresses keep the editor open with guidance. Edits retain
  link identity, creation date, verse/edition anchors and folder assignments.
- Drag directly listed study material onto a subfolder to move it there. Only the
  current folder assignment changes; other assignments remain. No Folder can file
  unfiled items. Locked, inactive and stale routes reject moves without partial
  changes. Folder reparenting retains its separate drag type and command.
- Arrange, New Subfolder, Study Material View and Add section controls now show
  icons only, retaining descriptive accessibility names and 44-point touch targets.

## Points to Ponder

Delete is now a filled red button matching Explore's size. The question modal fits
its content vertically with comfortable margins and a compact Close header, instead
of leaving a large empty area below the actions. Constrained layouts can scroll.
The existing Delete confirmation, Trash retention and Explore → Note flow remain.

## Compatibility and acceptance

No storage migration/reset is required. Existing app data and provider keys remain.
Study material drag payloads stay within this app and contain only item/source IDs;
access and current membership are rechecked when received. The compact sheet uses
content fitting on iPadOS 18+, with measured-height fallback on iPadOS 17.

Final local verification passed **406 unit tests and three UI journeys, zero
failures**, in `build/v131-release/verification.xcresult`: link edit/drag/relaunch,
compact question actions/Explore and nested-folder/icon controls. Signed build,
strict signature/identity checks, in-place install and normal launch passed on the
owner's iPad as 1.3.1/build 26. Final release evidence is recorded in
[SP-047](../../tickets/SP-047-link-editing-and-study-material-drag.md) and
[SP-046](../../tickets/SP-046-points-to-ponder-and-study-conversions.md).
Physical drag/Pencil, accessibility, split view, large-text and iPadOS 17 fallback
acceptance remain owner checks. This is a personal source release. The hosted
Release workflow verifies build and unit tests before creating the tag/release.
