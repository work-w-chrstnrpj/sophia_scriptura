# Sophia Scriptura v1.3.2

Release date: **2026-10-18**. App version **1.3.2**, build **27**.

## Quiz Me reliability

- Start a ready quiz, another round or an exam from its prepared questions without
  waiting for a provider refill. Cold preparation requests only the missing questions;
  an exam with 24 ready questions needs one more to start a 25-question session.
- Refill starts when questions are reserved, while the quiz is active. Each scoped
  type/difficulty bucket has a 100-question low-water target and 200-question capacity,
  with provider requests in batches of at most ten. Playable buckets are prioritized
  before deeper refill, with fair batch scheduling, shared in-flight generation and
  bounded retries.
- Persist each validated merged batch before requesting the next one. Repeated view
  loads no longer reload an older snapshot over a live session. Foreground return
  reconciles refill demand; existing unused questions remain in local storage.
- Quiz again and Done use matching expanding button-label geometry. Setup and Settings
  descriptions now explain readiness and replenishment accurately.

## Compatibility and acceptance

No storage schema migration, reset or question recycling is introduced. Existing
study data, provider keys and edition/provider/model-scoped banks remain intact.
Refill runs within the app's execution lifetime; it is not a permanent background
service. iPadOS can suspend generation, with demand reconciled on foreground return.
