# Sophia Scriptura v1.4.0

Release date: **2026-10-20**. App version **1.4.0**, build **28**.

## Collection Plans

- Create Plans with configurable Day/Section labels and ordered Scripture, note and
  link assignments. Scripture entry supports verse ranges and whole chapters;
  Scripture, Notes and Links have separate assignment tabs.
- Open Plan contents first, with explicit editing. Start/Resume uses the existing
  Scripture reader, full book names, dimmed surrounding verses and durable Next
  completion. Reading pauses at section summaries.
- Previous, Add Note, Add Link, Background Music and Next remain available. Notes and
  links created while reading are checked; notes open in the shared editor for preview.
- Manage assignments, sections, reset, duplication, archive and Trash. Structural edits
  use stable identities, fixing the section-removal exclusivity crash and guarding
  stale callbacks. Batch replacement retains every selected chapter.
- Completed Plans display the matching Notes-style distressed COMPLETED stamp only
  on their outside Collection list/card record. It disappears after resetting progress.
- Collections uses Items and Add Items. Lifecycle actions have icons; Trash is red.

## Reading position and durability

Reader startup loads its saved location before any early shell/lifecycle write, keeping
its last book/chapter rather than overwriting it with an empty startup snapshot.
Collections/Notes generations include Plan values, copied access requirements and
backup recovery support. Existing supported legacy formats remain readable; activated
Collections schema 4 and Notes schema 5 prevent old-reader fallback from silently
stripping Plan data. Full backup writes version 2. No uninstall/reset is required.
