# Sophia Scriptura v1.5.0

Release date: **2026-10-25**. App version **1.5.0**, build **29**.

## Plan editing and autosave

- Edit the main Plan screen directly, with the existing authoring features and autosave.
- Prominent assignment actions and stable ordering controls make authoring clearer.
- Plan edits debounce and serialize writes; Done/Exit flush pending changes.
- Notes metadata, object and Prayer-update editors, Collection details, links and
  gleanings feed their owning stores' autosave. Invalid input retains the last valid save.

## Plan folders and lifecycle

- Each Plan owns a mandatory, fixed Plan folder with named Day/Section subfolders.
  Its root contains the shared Plan; section children contain their assignments.
- New notes and links file into the corresponding section folder. Existing items
  retain shared identities rather than being cloned.
- Deleting either the Plan or its folder confirms the paired deletion and moves the
  managed tree to Trash. Items shared elsewhere remain in their other locations.
  Restore recovers the group; interrupted Notes phases are recoverable.
- Progress captions count completed Days/Sections. Empty sections are not completed.
- Edit Scripture assignments from the Plan or its section-folder item. Both entry
  points seed the current selection and update the same assignment. Folder navigation
  carries the shared reader into nested folders.

## Compatibility and verification

Collections schema 5 retains supported legacy reads and records paired Trash recovery.
Older app versions must not write activated lifecycle data. Keep this version or newer
when continuing to edit these stores. No uninstall or study-data reset is required.

Final versioned verification passed **481 unit tests and three native UI journeys**:
inline editing/autosave after relaunch, shared Scripture editing, and paired deletion/
section progress. The lifecycle journey passed after disambiguating a test selector;
product source was unchanged. Evidence is recorded in SP-053 and
`build/v1.5.0-release/`.

This is a personal source release. Physical Pencil, drag feel, accessibility, privacy
and owner workflow acceptance remain open. SP-050–052, live-provider quality and
commercial distribution permissions are separate scope. Final v1.5.0/build 29 passed signed in-place installation and normal launch on
iPad ni Paj; the device app query confirms the version, build and bundle identity.
Installation and launch evidence do not establish physical feature acceptance.
