# Sophia Scriptura v1.6.0

Release date: **2026-10-30**. App version **1.6.0**, build **30**.

## Plans and Activity

- Play/Resume reads one Day/section at a time. Completion saves Activity History,
  shows congratulations and exits. Tap a Day title to start/resume that exact Day.
- Activity type is selectable in Edit; missing values default to Reading. Timers
  are named `Plan name - Day/section`. Unrelated running activities are preserved.
- Stopping halfway pauses the timer with no History entry and keeps checked assignments.
  Switching Days in the same Plan retains paused time across relaunch. Completing a
  reread creates a new record without erasing earlier checks/completion dates.
- New Conversation sits between Link and Music, using existing Companion defaults
  and explicit Send. Missing-provider feedback stays within the Plan.
- Optional Strict plan mode uses a chosen start date or first Play. Due/completion
  captions appear once below each Day and in Edit, with plain Day headings.
- Edit offers explicit Catch up when unfinished work is overdue. It schedules unfinished
  Days in order from today while preserving completed dates and checked assignments.

## Collections and Prayer

- Plan folder names follow the complete title throughout autosave. Existing shortened
  roots reconcile through the checked save/startup path without replacing folders.
  Custom descriptions, folder locations, shared materials and identities are retained.
- Saving a new Plan closes both its editor and Add Items. Collections header spacing
  separates Lock and Archived Plans with consistent icon sizing.
- Prayer Clear moves into More actions with its existing confirmation. Links, bookmarks
  and gleanings still have no individual Archive action; their Collection can be archived.

## Compatibility

No store reset or one-time conversion is required. Plan schedule/activity settings,
section dates, cursor session IDs, Activity Plan/section IDs and retained paused drafts
are additive optional fields; supported earlier stores/backups remain readable. Existing
Plans default to Reading with strict dates off. Current backups preserve paused Day timers.
Older readers may discard new optional fields on rewrite; retain this build or newer
when using these features. Existing historical Activity records are not deleted.

zero failures/skips (`build/v1.6.0-release/final.xcresult`). UI covers staged full-title
folder naming/creation dismissal, Prayer Clear in More with confirmation, partial progress
and no History after relaunch, direct Day selection/chapter, single date captions and
completed named History. SP-054–056 retain implementation evidence and acceptance limits.

passed for **1.6.0/build 30**, confirmed by the device app query. Evidence is in
`build/v1.6.0-release/`, the [testing specification](../testing/test-specification.md),

The hosted Release workflow verifies the merge commit before publishing its immutable tag
and source release; no personally provisioned binary or user data is attached.

feature/landscape/accessibility, Pencil/privacy and live-provider acceptance remain open.
Physical UI automation was blocked by missing Xcode account/test-runner provisioning;
