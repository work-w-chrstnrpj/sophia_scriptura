# Sophia Scriptura v1.6.1

Release date: **2026-10-31**. App version **1.6.1**, build **31**.

## Prayer and Notes

- Compact Prayer balances top and side text margins using the actual available width in portrait and landscape. Long prayers and saved handwriting remain vertically scrollable, with complete text fitting horizontally.
- Maximized Prayer shows visible gray **dashed** boundaries around the writing region visible in the compact board. The guides do not intercept input or alter handwriting.
- More inside every note now includes its metadata editor: **Edit Note**, **Edit Canvas**, **Edit Journal**, or **Edit Prayer**. Change title, tags, paper and library/card color directly from either Notes or Collections. The existing library Edit action remains available.

## Compatibility

Stored text, original Pencil coordinates and drawing bytes are preserved. Existing Notes stores and backups require no reset, transformation or schema change. Color remains the note's library/card accent; the writing surface follows the appearance theme.
