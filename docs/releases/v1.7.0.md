# Sophia Scriptura v1.7.0

Release date: **2026-11-02**. App version **1.7.0**, build **32**.

## Plans and Lady Wisdom (SP-058)

- The active Activity recorder and enabled Lady Wisdom stay available above a fullscreen Plan, including while reading. Finish exits safely into the existing Stop Plan Activity flow.
- Plan Edit adds **Add multiple sections…** alongside one-tap Add section. Existing identities, assignments, completion and folders are preserved.
- **Share with Lady Wisdom** explicitly attaches a saved Plan (title, section names and Scripture references only; protected Plans and note bodies are never sent). Sophy can propose added sections and Scripture assignments, previewed before an atomic save; Cancel writes nothing.

## Interface polish

- Tab dock: aligned labels, filled accent icon for the selected tab, and a clearer chevron handle when the dock is hidden.
- The dock stays pinned on Collections, Notes, Activity and Settings, and auto-hides only in Scripture, Companion chat, full-screen note editing and Plan playback. It stays behind the keyboard. The music button hides together with the dock.
- Cards across Settings and Activity use one opaque card surface with a hairline border and soft light-mode shadow; note cards share the same tone.
- Notes and Collections group header commands into a single cluster. When tab shortcuts are on, the header **+** gives way to the shell's Add capsule. Archived Collections and Archived Plans share one Archive menu.
- Settings is centered at a readable width, every section has a tinted icon heading, and regular-width iPads show a section index sidebar.
- Companion's empty state, the passage picker in wide portrait, and the "New Note" label are refined. Leaving Scripture switches tabs immediately while annotation saving finishes in the background (an in-progress Pencil stroke still saves first).

## Compatibility

No Plan schema, backup format, signing identity or data reset changes. Sophy history gains an additive Plan-update action; older binaries may reject that new history while retaining recovery generations.
