# Sophia Scriptura v1.7.1

Release date: **2026-11-05**. App version **1.7.1**, build **33**.

## Plans: choose the translation

- Plan Edit now has a **Translation** picker in the Plan section. It replaces the "Use current translation" button and lists the bundled World English Bible plus every installed AO Lab and downloaded API.Bible translation. If a Plan uses a translation that is no longer installed, it stays listed as "not downloaded" so the Plan is never silently changed.
- Switching translation updates the Plan's existing Scripture assignments and reading position to the new translation. Before saving, the app confirms each assigned chapter and verse range exists in that translation; if one does not, the Plan is not saved and an error is shown.
- New Plans start in the Reader's current translation. When the Reader has not loaded yet, they now use the Reader's saved translation instead of falling back to WEB.

### Why Plans kept starting in WEB

New Plans copy the Reader's translation, and playing a Plan switches the Reader to that Plan's translation. Once a WEB Plan was played, the Reader stayed on WEB and every later Plan inherited it. Playback behavior is unchanged in this release; the new picker lets you set each Plan's translation directly.

## Settings

- Tapping the **Settings** title shows or hides the section index sidebar on regular-width iPads. No extra icon is added. The sidebar starts hidden and the app remembers your choice. Narrow layouts, which have no sidebar, are unchanged.

## Compatibility

No Plan schema, backup format, signing identity or data reset changes. Existing Plans keep their translation until you change it.

## Verification and limits

**512 unit tests passed, zero failures, zero skips** (`SophiaScripturaTests`, iPad (A16) simulator, iOS 27.0; `build/v1.7.1/unit.xcresult`). No new automated test covers the translation picker or the Settings title toggle; both are UI-only changes checked by build and device install. The change set was installed in place on the owner's iPad before the version bump and launched normally. Physical owner acceptance of translation switching on Plans with existing assignments remains an owner check. The hosted Release workflow verifies the main merge before publishing source/tag.
