# Sophia Scriptura v1.8.0

Release date **2026-11-08**. App version **1.8.0**, build **34**.

## Plan study experience

- In Progress Plan cards show a traveler at the current fraction of completed sections. On return from a completed section, the traveler walks to the new position. At the end of the Plan, the final walk leads into the Completed stamp.
- Long-press a Plan card and choose **Edit** to select Sophy, Sabinus or Sol, an outfit color, scenery and equipment. Options include a candle, a lantern that lights the path, and the Armor of God. Sunny and Moonlit scenery feature soft halos, drifting clouds, and pulsing rays or twinkling stars. Automatic follows the app appearance. Reduce Motion shows a still scene.
- Strict Plans offer one-time reminders for unfinished sections due today or tomorrow. Plan Edit sets the initial reminder time, and Activity → Reminders can adjust the occurrence or the future time. Opening Sophia refreshes the reminder window.
- Tapping a Scripture assignment opens the shared reader inside the Plan, with assigned verses highlighted and surrounding verses dimmed. Draw uses one named Pencil layer per section, with separate drawings for each source chapter.
- New Companion conversations open within the Plan. Scripture or typed note content is attached to the prompt when eligible, and new chats take a title from the assignment or the first question.

## Compatibility

Existing Plans use Sophy, the character's default outfit, cloudy scenery and a candle when the new preferences are absent. This build reads earlier annotation snapshots. Plan-owned drawings use annotation snapshot v2 and require v1.8.0 or later.

## Verification

All 525 local native tests passed on the iPad Air 13-inch (M4) simulator. Focused simulator journeys covered Scripture review and layer reuse, returning to the Plan card, and the final walk before the completion stamp.

The owner tested the final SP-059 build on iPad, confirmed the appearance and approved ticket closure. That build was installed in place as 1.7.1 (build 33) before the release version bump. Physical Pencil interaction, system notification delivery and live-provider behavior remain separate verification items.
