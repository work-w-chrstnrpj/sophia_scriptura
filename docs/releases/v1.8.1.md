# Sophia Scriptura v1.8.1

Release date **2026-11-09**. App version **1.8.1**, build **35**.

## Plan conversations are saved to the Plan

- A conversation started with **New conversation** while reading a Plan assignment or previewing a Plan note is added to the Plan as a completed assignment directly after its source item, the same way **Add new note** and **Add new link** work.
- The conversation is filed in that section's Plan materials folder in Collections.
- Tapping the conversation in the Plan list, or reaching it with **Next**, reopens it in the Plan's Companion panel. Plan Edit lists it as "(Conversation)".

## Qwen (International) free-quota models

- Qwen (International) lists the owner's free-quota text models first, in priority order: `qwen-flash`, `qwen3.5-flash`, `qwen3.6-flash`, `qwen3.7-flash`, `qwen3.8-flash`, `qwen-flash-2025-07-28`, `deepseek-v4.1-flash`, `qwen-plus`, `qwen3.5-plus`, `qwen3.6-plus`, `qwen3.7-plus`, `qwen-plus-latest`, `qwen-max`, `qwen3.7-max`.
- Language models with free quota in the 2026-11-09 Singapore console capture are labeled free, and the free-only filter is available.
- When Alibaba returns HTTP 403 `AllocationQuota.FreeTierOnly` before a response starts, Companion, Quiz and Sophy requests retry with the next model in the list. The conversation records the model that answered, and exhausted models are skipped until the app restarts.
- Qwen (China) is unchanged.

Fallback requires Stop-on-Exhaust (Free Only) in Model Studio; without it, Alibaba bills usage instead of returning 403. The free-quota list is a fixed capture; it is not read from the provider and must be updated in `ProviderModelCatalog.swift` when quotas change.

## Compatibility

A Plan that contains a conversation assignment requires v1.8.1 or later. Existing Plans are unchanged.

## Verification

All 528 local native tests passed on the iPad (A16) simulator, including new tests for conversation assignment and filing, Qwen International model priority, and quota-exhaustion fallback with session skipping.

Live Alibaba quota exhaustion and owner-device walkthroughs of the Plan conversation flow remain separate verification items.
