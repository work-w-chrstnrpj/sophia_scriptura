# Sophia Scriptura v1.9.0

Release date **2026-11-12**. App version **1.9.0**, build **36**.

## Plan Scripture assignments

- **Verse wheels.** Adding or editing a verse range uses First verse and Last verse scroll wheels. They list only the verses that exist in the chosen chapter, and Last verse starts at First verse, so a range can no longer run past the end of a chapter.
- **Edit Scripture.** In Plan Edit, tapping a Scripture assignment, or choosing **Edit Scripture** in its menu, opens a Scripture-only editor already filled with the current reference. Other assignment types keep **Replace assignment**.

## Plan overview

- **Type labels instead of previews.** Note body previews and the "Preview note" line are gone. Each assignment shows its type under the title: Scripture, Link, Conversation, or the note type (Page, Canvas, Prayer, Journal).
- **List, Carousel and Tile views.** Plan Edit has a new **Plan view** setting, saved per Plan (default List).
  - **List:** every day with its assignments, as before.
  - **Carousel:** one large card per day that you swipe left and right.
  - **Tile:** equal tiles showing only the day name; tapping a tile plays that day.
- **Completed days are locked.** A day counts as completed when every assignment is checked, however it was checked. In the Plan overview and in Plan Edit, a completed day cannot be unchecked. It is greyed out in Edit with "Completed · Reset to change". An unfinished day can be checked and unchecked freely. **Reset section** or **Reset whole Plan** is the way to reopen a completed day.
- The check circle on each assignment in the Plan overview now toggles completion directly; tapping the rest of the row opens the assignment.

## Pencil layers follow the Plan's Bible version

- Plan ink is saved per day and per translation. When the Plan's translation changes and a passage already has ink in another version, a blank layer for the new version is created automatically, and the old ink is kept.
- A **Layer** menu appears above such a passage and switches between versions. Choosing an older version shows the passage in that translation so the ink stays aligned.
- Extra layers are never created by hand; the first layer is still created with **Draw**.

## Notes

- The Notes filter menu has **Hide Plan notes**, which hides notes created for a Plan or assigned to one. The setting is remembered, and the view label shows "No Plan notes" while it is on.

## Compatibility

Plans gain an optional `viewLayout` field (absent means List). Older builds ignore the field. No migration is needed, and existing Plans are unchanged. See the [Plans contract](../data/collection-plans-contract.md).

## Verification

All 528 local native tests passed on the iPad (A16) simulator. This release adds no new automated tests. One UI test was updated for the verse wheels and was not run. The installed iPad build has not yet been walked through on the device for the verse wheels, Carousel and Tile views, completed-day locking, the Hide Plan notes filter, or the per-version Pencil layer switch. Viewing an older version's layer needs that translation to be available on the device.

This is a source release for personal iPad installation. See the [deployment guide](../deployment/deployment.md).
