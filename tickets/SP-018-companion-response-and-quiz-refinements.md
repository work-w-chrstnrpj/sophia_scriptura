# SP-018 — Companion response and Quiz Me refinements

- Type: implementation. Status: baseline owner verified on physical iPad 2026-10-04;
  OLA and manual Ask follow-ups implemented, focused regression passed; owner acceptance pending.
- Milestone: M6 Stateful Companion.
- Selected by owner: 2026-10-02.

## Visible outcome

- Provider responses are explicitly requested as readable Markdown rather than one unbroken
  paragraph, using the existing safe Markdown renderer.
- Scripture selection adds Original Language Analysis beside Ask and prepares a structured,
  passage-linked Hebrew/Aramaic/Koine Greek contextual-analysis draft.
- Identify the Reference is removed from new Quiz Me setup, Bible Quiz replaces it, and
  Bible or False is added with provider-generated keys, explanations and cited references.
- Companion saves are serialized so overlapping UI changes do not produce a false stale-save
  alert at launch.
- Notes cards, rows and details show their persisted Created and Last modified timestamps.
- Companion uses the same shared heading-font preset and 24-point scaled title treatment as
  the Notes library.
- New quizzes are generated by the selected provider using a strict JSON contract. The prompt
  excludes the latest 10 questions for each selected game type and applies separate Easy,
  Average and Difficult rubrics.

## Exclusions

- Do not add providers or change Activity behavior.
- Previously persisted Identify the Reference sessions remain decodable for compatibility.

## Affected implementation

- Companion context builder and Scripture selection routing.
- Provider-neutral AI quiz request/response validation, recent-question context and Quiz Me UI.
- Companion save coordination and Notes metadata presentation.
- Focused Companion tests and M6 product/design/testing documentation.

## Acceptance

- Every provider request receives the same Markdown response-format instruction.
- Original Language Analysis is separately discoverable in the Scripture selection menu and
  requests original wording, grammar, context, meaning and translation observations.
- New Quiz Me setup shows Bible Quiz and Bible or False but not Identify the Reference.
- The selected provider returns the complete structured question set before the quiz opens.
- Malformed, incomplete, duplicate or exact-recent questions are rejected instead of saved.
- For ordinary multiple-choice games, Sophia repositions the keyed answer locally across
  available choice positions; True/False and Scripture/Cap retain conventional ordering.
- Up to 10 latest prompts per selected type are sent as exclusions; difficulty rubrics are
  materially distinct in the provider instruction.
- AI-generated answer keys and cited references are disclosed in setup and feedback; saved
  legacy sessions still decode.
- Rapid consecutive Companion mutations save sequentially without a stale-revision notice.
- Notes show labeled Created and Last modified values without changing the Notes schema.
